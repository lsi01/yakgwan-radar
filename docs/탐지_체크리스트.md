# 탐지 체크리스트 v1 — 보험약관

LLM 분석기 A/B의 프롬프트 뼈대. 각 항목 = 조항을 훑을 때 찾아야 할 패턴 + 위험 신호 표현 +
근거(표준약관·법령) + 소비자에게 돌려줄 설명/질문. 조항 단위 분석 시 이 카테고리로 분류(`유형`).

위험도 기준(공통):
- **높음**: 표준약관보다 명백히 불리 / 필수 아님을 오도 / 소비자 권리를 실질 제한
- **중간**: 업계 관행이나 소비자가 놓치기 쉽고 금전적 영향 큼
- **낮음**: 표준적이나 소비자가 알아둘 필요 있음

## 분석기 A — 소비자 불리 조항

### A1. 보장 제외 / 면책 사유
- 찾을 것: "보상하지 않습니다", "면책", "보장에서 제외", 특정 질병·상황 배제
- 위험 신호: 표준약관 면책 범위를 넘어서는 추가 배제 / 포괄적·모호한 배제("기타 이와 유사한") / 정신질환·자해·특정 부위 광범위 제외
- 근거: 생명보험 표준약관·질병상해보험 표준약관의 "보험금을 지급하지 않는 사유" 조항, 실손의료비보험 표준약관 면책 목록
- 참고 통계: 보험금 부지급 사유의 약 85%가 "약관상 면·부책"
- 소비자 질문: "이 면책 항목이 표준약관에도 있는 내용인가요? 추가된 배제는 무엇인가요?"

### A2. 지급 사유 축소 정의 (용어 정의로 보장 좁히기)
- 찾을 것: "제1조(정의)" 및 개별 담보의 용어 정의 — "암", "중대한 질병", "질병", "상해", "입원", "수술"
- 위험 신호: 진단 분류표·약관상 정의가 통상적 의학 정의보다 좁음 / "약관에서 정한" 특정 코드에만 해당 / 경계성·제자리암 등 감액 대상
- 근거: 표준약관 별표(용어 정의, 대상 질병 분류)
- 소비자 질문: "내가 생각하는 '암/입원/수술'과 약관의 정의가 다른 부분이 있나요?"

### A3. 면책기간 / 감액지급 기간 / 대기기간
- 찾을 것: "계약일부터 N일(년) 이내", "면책기간", "감액", "50%만 지급"
- 위험 신호: 표준 대비 긴 감액기간 / 감액비율 큼 / 갱신 때마다 대기기간 재적용
- 근거: 표준약관의 보장개시일·감액지급 규정
- 소비자 질문: "가입 후 언제부터 100% 보장되나요? 그 전에 사고가 나면 얼마를 받나요?"

### A4. 갱신형 보험료 인상 구조
- 찾을 것: "갱신", "갱신 시 보험료는 변경", "위험률 변동", "연령 증가에 따라"
- 위험 신호: 인상 상한 없음 / 갱신 거절 가능 / 비갱신처럼 오인될 표현과 혼재 / 무·저해지 환급형인데 갱신 부담 병존
- 근거: 금융소비자보호법상 설명의무(보험료 변동 가능성), 표준약관 갱신 규정
- 소비자 질문: "10년/20년 뒤 보험료가 얼마까지 오를 수 있나요? 상한이 있나요?"

### A5. 해지환급금 / 무·저해지 환급형
- 찾을 것: "해지환급금", "무해지", "저해지", "납입기간 중 해지 시 환급금이 없거나 적음"
- 위험 신호: 초·중기 환급금 0 또는 극소 / 표준형과 환급금 비교표 부재 / "만기 시 100% 환급"만 강조
- 근거: 금소법 부당권유 금지(불확실한 사항 단정적 표현), 표준약관 해지환급금 규정
- 소비자 질문: "5년/10년 시점에 해지하면 낸 돈 대비 얼마를 돌려받나요?"

### A6. 고지의무 / 계약 전 알릴 의무와 해지권

- 위험 신호: 고지의무 위반 시 인과관계 불문 전면 부지급으로 읽히는 표현 / 해지권 제척기간(제한) 미기재
- 근거: 상법 651조, 표준약관 "계약 전 알릴 의무 위반의 효과", 인과관계 부존재 시 지급 규정
- 소비자 질문: "고지 누락과 무관한 질병도 보험금을 못 받나요? 회사가 해지할 수 있는 기간 제한은요?"

### A7. 자동갱신 / 자동이체 / 계약 유지 관련

- 소비자 질문: "갱신을 원치 않으면 언제까지 어떻게 알려야 하나요?"

### A8. 보험금 청구 절차·서류·기한 부담

- 근거: 표준약관 "보험금 지급절차", 지급기일·지연이자 규정
- 소비자 질문: "서류를 다 내면 며칠 안에 지급되나요? 늦어지면 이자를 주나요?"

### A9. 분쟁 해결 / 관할 / 소멸시효
- 찾을 것: "관할법원", "중재", "소송", "소멸시효", "3년"

- 근거: 약관규제법(신의칙 위반 조항 무효), 표준약관 관할 규정
- 소비자 질문: "분쟁이 생기면 어디에 조정을 신청할 수 있나요?"

### A10. 계약자 배당 / 사업비 / 공시이율·예정이율

- 소비자 질문: "내가 낸 보험료 중 실제 적립되는 비율은 얼마인가요?"
