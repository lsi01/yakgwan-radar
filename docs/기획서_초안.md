# 2026 금융 AI Challenge 기획서 초안

> 첨부1 `(첨부1) 2026 금융 AI Challenge 공모전 기획서.hwpx` 양식에 옮겨 넣을 초안.
> 팀명·구성원 성명은 등록 계정과 동일하게 직접 기재.
> 분량은 양식에 맞춰 조정(핵심만 남기고 줄이기).

---

## 1. 서비스 명칭

**약관 레이더 (YAKGWAN RADAR)** — 보험 약관 PDF를 올리면 소비자에게 불리한 조항과 과도한 개인정보 조항을 레이더처럼 탐지해, 약관 원문·법령 근거와 함께 쉬운 말로 알려주는 AI 웹서비스.

> 대안(더 부드러운 톤 원할 시): **약관 렌즈 (Policy Lens)** — 약관을 확대해 들여다본다.

## 2. 아이디어 기획 핵심내용 (요약, 개조식)

- **입력**: 사용자가 보험 약관·상품설명서 PDF를 업로드 (또는 공개 다이렉트 약관 선택)
- **처리**: 생성형 AI가 약관 전문을 구간별로 읽어
  - (A) 소비자 불리 조항 10개 유형 — 면책·부지급, 지급범위 축소 정의, 감액·대기기간, 갱신보험료 인상, 무·저해지 환급, 고지의무 효과, 자동갱신, 청구 부담, 관할·시효, 사업비·공시이율
  - (B) 개인정보 조항 8개 유형 — 필수/선택 동의 오도, 과다 수집, 제3자 제공 범위, 마케팅 활용, 보유기간, 처리위탁, 정보주체 권리, 자동화 의사결정
  - 을 탐지하고 **약관 원문 그대로 발췌 + 위험도(높음/중간/낮음) + 표준약관·법령 근거 + 소비자 확인 질문**을 생성
- **출력**: 종합 "소비자 유의도" 점수 + 카테고리별 점수 + 조항별 카드. "근거 자세히"(법령 상세 해설)·"질문 더 보기" 확장
- **눈높이 선택**: 일반 / 사회초년생 / 고령자 — 같은 조항을 대상 독자에 맞춰 다르게 설명
- **핵심 가치**: "요약"이 아니라 **약관 원문 인용 + 법령 대조** → 소비자가 실제 약관을 스스로 검증하도록 지원

## 3. 문제 정의 및 제안 배경

### 해결하려는 문제

- **문제는 '판매 시점'이 아니라 '청구 시점'에 드러난다**: 판매 시점의 불완전판매비율은 2023년 0.03%로 낮지만(금감원), 정작 보험금 청구 단계의 분쟁은 늘고 있다. 금감원 「2024년 상반기 금융민원 동향」에 따르면 손해보험 민원은 전년 동기 대비 +10.1%(19,668건), 그중 **실손 등 보험금 부지급 분쟁은 +31.6%(3,490건)** 증가했다.
- **부지급의 대부분은 '약관을 몰라서'**: 2025년 자산 10조 원 이상 손해보험 9개사 기준, 보험금 부지급 사유의 **85.2%가 "약관상 면·부책"**(약관 규정에 따라 지급하지 않는 경우)이었다(소비자주권시민회의 분석, 2026.6, 각 사 공시 자료 취합). 소비자가 약관 내용을 충분히 이해하지 못한 채 가입했음을 시사한다.
- **소비자는 약관을 읽을 수단이 없다**: 약관은 수십~수백 페이지이고, 불완전판매(중요사항 누락·과장 설명, 약관·상품설명서 미교부, 자필서명 대필 등)를 소비자 스스로 걸러낼 방법이 없다.
- **개인정보 동의의 형식화**: 필수/선택 동의가 구분되지 않거나 선택 항목이 필수처럼 배치되고, "보험관련단체 등"처럼 제3자 제공 범위가 열려 있어 소비자가 어디까지 동의하는지 알 수 없다.

### 타겟 고객 — 왜 이들인가

- **사회초년생 (20대~30대 초)**: 생애 첫 보험을 스스로 가입하는 시점. 금융·법률 용어 이해도가 낮고, 갱신형·무·저해지 환급형처럼 장기 비용 구조가 복잡한 상품에 특히 취약하다. "예시표"만 보고 판단하기 쉽다.
- **고령층·장애인 등 디지털 취약계층**: 디지털·금융 리터러시가 낮아 약관을 읽어도 의미를 파악하기 어렵고, 대리 가입·불완전판매의 표적이 되기 쉽다. → **눈높이별 설명 + 글씨 크기 조절**로 접근성을 확보한다.
- (확장) 금융소비자 일반, 감독기관·협회의 불완전판매 모니터링, 금융사 내부 약관 셀프 점검

### 채널 — 왜 이 채널인가

- **비대면·다이렉트(CM) 채널**: 자동차보험·미니보험 등 단순 상품 위주지만 젊은 층을 중심으로 빠르게 확대되고 있고, 향후 복잡 상품으로 넓어질 채널이다. 설계사 대면 설명이 없어 **약관을 검증해 줄 제3자 도구가 전무한, 소비자 보호 장치가 가장 취약한 채널**이다.
- **가입 직전·직후 시점**: 약관 PDF만 있으면 즉시 점검할 수 있어야 한다. 웹서비스로 제공해 별도 설치 없이 PC·모바일 어디서나 접근한다.
- 대회 주제에 대응: "금융소비자 특성(사회초년생·고령층의 낮은 금융·디지털 리터러시)과 서비스 채널(비대면·다이렉트)을 고려한 맞춤형 금융 AI 서비스"를 지향한다.

## 4. 서비스 컨셉 및 차별성

### 핵심 컨셉

"약관을 대신 읽어주는" 것을 넘어, **약관의 특정 문장을 지목해 "이 부분이 왜 불리한지"를 표준약관·법령과 대조해 설명**하고, 소비자가 상담 창구에서 그대로 물어볼 질문을 쥐여주는 서비스.

### 기존 금융 앱·서비스 대비 차별성

| 구분 | 일반적인 약관 요약/챗봇 | 약관 레이더 |
|---|---|---|
| 결과 형태 | 약관을 짧게 요약 | **약관 원문 문장 그대로 인용** + 위험도 + 페이지 |
| 판단 근거 | LLM의 일반 지식 | 표준약관·금소법·개인정보보호법 등 **조문 요지와 대조**, "근거 자세히"로 상세 해설 |
| 대상 범위 | 보장 내용 중심 | **소비자 불리 조항 + 개인정보 조항**을 함께 (소비자보호 + 개인정보보호) |
| 사용자 맞춤 | 단일 톤 | 일반/사회초년생/고령자 **눈높이별 설명**, 글씨 크기 조절 |
| 행동 연결 | 설명에서 끝 | **가입 전 확인 질문** 생성, "질문 더 보기"로 확장 |

- **기존 보험 서비스와의 차이**: 보험다모아·굿리치·보맵 등은 **상품 비교·가입 중개**이지, 특정 약관의 조항 단위 위험을 원문·법령과 대조해 분석하지 않는다. "약관 조항을 지목해 불리 여부와 근거를 제시"하는 소비자용 서비스는 사실상 공백이다.
- **주최기관 정합성**: 소비자보호(금융위·금융소비자보호법)와 개인정보·전자금융보안(금융보안원) 두 축을 한 서비스에서 다룬다.
- **확장성**: 동일 엔진으로 대출 약정서·투자상품 설명서까지 → 공동개최사(은행·증권·생보) 상품군 전반 커버.

## 5. 활용 데이터 및 생성형 AI 모델 적용 방안

### 활용 데이터

| 데이터 | 종류 | 수집·활용 |
|---|---|---|
| 보험 약관·상품설명서 PDF | 비정형 문서 | 사용자 업로드 또는 보험사 공개 다이렉트 약관. 텍스트 추출 후 **분석에만 사용, 저장·학습하지 않음** |
| 표준약관 | 준정형 텍스트 | 금융감독원 금융소비자보호포털 공개 표준약관(생명·질병상해·실손) — 근거 대조용 |
| 관계 법령 조문 | 텍스트 | 금융소비자보호법, 개인정보보호법, 신용정보법, 약관규제법, 상법(보험편), 정보통신망법 — 조문 요지를 근거 코퍼스로 구축 |
| 탐지 체크리스트 | 규칙 정의 | 소비자 불리 조항 10유형·개인정보 조항 8유형을 각 위험 신호·근거·질문과 함께 정의 |

### 생성형 AI 모델의 역할 (서비스 내 구체적 활용)

생성형 LLM이 파이프라인의 **핵심 엔진**이며, 다음 6가지를 수행:

1. **조항 추출** — 다단 편집으로 줄이 뒤섞이고 목차·특약·별표가 섞인 약관 원문에서 실제 조항 단위를 식별 (규칙·정규식으로는 실패)
2. **유형 분류** — 각 조항을 체크리스트 A1~A10 / B1~B8 유형에 매핑, 해당 없으면 제외
3. **원문 발췌 + 위험도 판정** — 문제되는 문장을 그대로 인용하고 표준약관 대비 불리 정도를 3단계로 판정
4. **눈높이별 재작성** — 같은 조항을 일반/사회초년생/고령자 수준으로 다르게 설명
5. **확인 질문 생성** — 소비자가 상담 시 물어볼 구체적 질문, "더 보기" 시 중복 없이 추가
6. **법령 근거 해설** — 인용된 조항과 관련 법조문 요지를 엮어 "왜 불리한지 → 법은 어떻게 규율하는지 → 소비자 대응"의 상세 해설

- 구조화 출력(JSON 스키마)으로 결과를 안정적으로 수집, 문서 구간별 병렬 호출로 처리 시간 단축, 동일 문서는 캐싱해 재분석 비용 0
- 개인정보·민감정보: 업로드 문서는 분석 후 비저장, 모델 학습에 미사용

## 6. 기대 효과 및 확장 가능성

### 해결하는 문제와 기대 효과

- **부지급 분쟁의 사전 차단**: 부지급의 85.2%가 "약관상 면·부책"이고 관련 분쟁이 늘고 있는 상황에서, 가입 전 면책·부담보·감액 조항을 미리 확인하면 청구 단계의 분쟁을 줄일 수 있다.
- **금융 포용**: 사회초년생·고령층이 전문가 없이도 약관의 핵심 위험을 이해하고, 상담 창구에서 물어볼 질문을 확보한다.
- **개인정보 자기결정권 강화**: "동의 안 해도 되는 항목"을 명확히 인지해 과도한 수집·제공 동의를 걸러낸다.

### 이해관계자별 혜택

- **금융소비자**: 가입 전 리스크 점검, 상담 시 물어볼 질문 확보, 분쟁 시 근거 확인
- **감독기관·협회**: 약관 표준화·불완전판매 모니터링 보조 도구
- **금융회사**: 약관 배포 전 소비자 불리 조항·개인정보 조항 셀프 점검

### 확장 가능성

- **상품군 확장**: 대출 약정서, 투자상품 설명서, 전자금융거래 약관 → 은행·증권·생보 전 상품
- **타 영역 확장**: 통신·구독 서비스 이용약관, 부동산 임대차 계약서, 근로계약서 등 "일반인이 읽기 어려운 계약 문서" 전반
- **형태 확장**: 금융사·핀테크에 API 제공, 마이데이터 연동 시 가입 상품 약관 자동 점검, 상담 창구용 도구

## 7. (자유 타이틀) — 예선 MVP 구현 현황

- 보험약관을 1차 타겟으로 웹서비스 구현 완료: PDF 업로드 → 진행 표시 → 소비자 유의도 점수 + 조항별 카드(위험도·약관 원문·페이지·법령 근거·확인 질문) + "근거 자세히"/"질문 더 보기" + 글씨 크기 조절
- 삼성화재 다이렉트 실손의료비보험 약관(157페이지)으로 검증 — 갱신보험료 할증 구조, 특정부위 부담보 기간, 서면조사 동의 강제, 개인정보 제3자 제공 범위 등 탐지
- 한계: 법령 근거는 현재 편집 요지 기반(원문 연동은 향후), 스캔 이미지 PDF 미지원
