## 1. MVP 구현 범위

**구현 완료 (예선 제출 MVP)**

- **대상**: 보험 약관(실손·질병·상해 등), 텍스트 추출이 가능한 PDF
- **분석 파이프라인**: PDF 업로드 또는 내장 샘플 선택 → 텍스트 추출·구간 분할 → 생성형 AI가 구간별로 (1) 실제 조항 식별 (2) 소비자 불리 조항 10유형(A1~A10)·개인정보 조항 8유형(B1~B8) 분류 (3) 약관 원문 발췌 + 위험도(높음/중간/낮음) 판정 (4) 표준약관·법령 근거 및 소비자 확인 질문 생성
- **결과 산출**: 8개 카테고리별 점수 + 종합 "소비자 유의도" 점수, 조항별 카드(위험도·약관 표기·페이지·원문 인용·근거·질문)
- **부가 기능**: 분석 진행 실시간 표시(SSE), 설명 눈높이 3단계(일반/사회초년생/고령자), 글씨 크기 조절(90~170%), "근거 자세히"(법령 상세 해설), "＋ 질문 더 보기"(확인 질문 추가), 동일 문서 결과 캐싱

**미구현 / 향후 (제출 범위 아님)**

- 스캔(이미지) PDF OCR
- 특별약관·별표 전 구간 심층 분석 (현재는 신호어 밀도 기준 상위 구간 선별)
- 법령 원문 실시간 연동 (현재는 편집 요지 코퍼스)
- 사용자 계정·분석 이력 저장
- 대출 약정서·투자상품 설명서 등 상품군 확장

## 3. 사용자 이용 흐름

1. **배포 URL(`https://yakgwan-radar.onrender.com`) 접속** → 메인 화면 (로그인 불필요). 무료 호스팅 특성상 장시간 미접속 후 첫 접속 시 최대 1분 내외 지연될 수 있음
2. (선택) **설명 눈높이** 선택(기본: 일반), **글씨 크기** 조절
3. **약관 PDF** 파일 선택 후 **[분석]** 클릭 — 또는 하단 **샘플 링크**(`samsungfire_silson.pdf`) 클릭
4. **분석 진행 패널**: "약관 텍스트 추출 중" → "N페이지에서 조항 검토 시작" → 진행바 "구간 k / M 검토 완료"(교육 카드 순환) → "근거 대조 및 점수 집계 중"
5. **결과 화면**
   - 상단(요약 카드): 문서명 / 페이지 수·분석 구간 수·눈높이 / 소비자 유의도 점수(0~100) / 카테고리별 막대
   - 하단(조항 카드 목록, 위험도순): 각 카드 = [위험도 뱃지 · 약관 표기(제○조 등) · 유형코드 · 페이지] / 지적 요지 / 약관 원문 인용 / 눈높이별 쉬운 설명 / 근거 + 법조문 요지 / 확인 질문 / [근거 자세히] [＋ 질문 더 보기]
6. **[근거 자세히]** 클릭 → 해당 조항의 상세 법령 해설 + 참고 조문 표시(다시 클릭 시 접기)
   **[＋ 질문 더 보기]** 클릭 → 확인 질문 3개 추가
7. 다른 약관 분석은 3번부터 반복 (동일 파일 재분석 시 캐시로 즉시 표시)

## 4. AI 및 데이터 처리 방식

### AI가 수행하는 역할

생성형 LLM(Anthropic Claude)이 파이프라인의 핵심 엔진이며, 다음을 수행:

1. **조항 추출** — 다단 편집으로 줄이 뒤섞이고 목차·특약·별표가 섞인 약관 텍스트에서 실제 조항 단위를 식별
2. **유형 분류** — 각 조항을 소비자 불리 조항(A1~A10) / 개인정보 조항(B1~B8)에 매핑, 해당 없으면 제외
3. **원문 발췌 + 위험도 판정** — 문제되는 문장을 그대로 인용, 표준약관 대비 불리 정도를 3단계로 판정
4. **눈높이별 재작성** — 같은 조항을 일반 / 사회초년생 / 고령자 수준으로 설명
5. **확인 질문 생성** — 소비자가 상담 시 물어볼 질문, "더 보기" 시 중복 없이 추가
6. **법령 근거 해설** — 인용 조항 + 관련 법조문 요지로 "왜 불리한지 → 법의 규율 → 소비자 대응" 상세 해설

### 사용 데이터 / 입력·출력

| 구분 | 내용 |
|---|---|
| 입력 데이터 | 사용자가 업로드한 약관 PDF(또는 내장 샘플). 서버에서 텍스트만 추출하며, 임시 파일은 처리 직후 삭제 |
| 참조 데이터 | 내장 탐지 체크리스트(불리 조항 10유형·개인정보 8유형 정의), 법령 조문 요지 코퍼스(금융소비자보호법·개인정보보호법·신용정보법·약관규제법·상법·정보통신망법), 표준약관 참조 |
| LLM 입력 | 약관 텍스트 구간 + 체크리스트 지침 (+ "자세히"·"질문 더 보기" 시 해당 조항 정보) |
| LLM 출력 | 구조화 JSON — 조항별 유형·위험도·약관 원문 발췌·설명·근거·확인 질문 |
| 최종 출력 | 소비자 유의도 점수 + 카테고리 점수 + 조항 카드 목록 (JSON → 화면 렌더) |

### 개인정보 또는 민감정보 처리 여부

- 서비스는 **사용자 로그인·회원가입·개인정보 수집을 하지 않음**
- 업로드한 약관 문서는 분석 목적에 한해 처리하며 **영구 저장하지 않음**(임시 파일 즉시 삭제)
- 분석 결과(JSON)는 성능을 위해 **파일 해시 기준으로 서버에 캐시**될 수 있으며, 개인 식별 정보를 포함하지 않음
- 업로드 문서·분석 결과는 **AI 모델 학습에 사용되지 않음**
- 표준 약관 PDF에는 통상 개인정보가 없으나, 사용자가 개인정보가 포함된 계약서를 올릴 경우를 대비해 저장 최소화 원칙을 적용

## 5. MVP 검증 방법

### 심사자 확인 절차

1. 배포 URL(`https://yakgwan-radar.onrender.com`) 접속 (로그인·설치 불필요). 무료 호스팅 특성상 장시간 미접속 후 첫 접속은 최대 1분 내외 지연될 수 있음
2. 하단 **샘플 링크(`samsungfire_silson.pdf`)** 클릭 — 최초 1회는 약 2~3분 소요(진행 패널 표시), 이후 캐시로 즉시
3. **결과 화면 확인**: 소비자 유의도 점수, 카테고리 막대, 조항 카드(위험도·제○조·페이지·약관 원문 인용·법조문 요지·확인 질문)
4. 임의 조항 카드에서 **[근거 자세히]** 클릭 → 상세 법령 해설 + 참고 조문 표시 확인
5. **[＋ 질문 더 보기]** 클릭 → 확인 질문 3개 추가 확인
6. **설명 눈높이**를 사회초년생/고령자로 변경 후 샘플 재클릭 → 설명 톤 변화 확인
7. **글씨 크기** 슬라이더 조절 → 화면 텍스트 크기 변화 확인
8. (선택) 텍스트 기반 보험 약관 PDF를 직접 업로드 → 동일 흐름 확인

### 테스트 입력값 / 예상 결과

| 입력 | 예상 결과 |
|---|---|
| 내장 샘플: 삼성화재 다이렉트 실손의료비보험 약관(157p) | 소비자 유의도 대략 50~60점대, 조항 카드 15~25건. 갱신보험료 할증(최대 300~400%), 특정 신체부위 부담보 기간, 보험금 청구 시 서면조사 동의 요구, 개인정보 제3자 제공 범위("보험관련단체 등") 등이 탐지됨 |
| 계정/샘플 입력값 | 별도 계정 불필요. 업로드 시 텍스트 PDF, 20MB 이하 |

### 실행 환경 / 브라우저 제한사항

- 최신 Chrome / Edge / Safari 권장
- 분석 진행 표시는 서버-전송 이벤트(SSE)를 사용하므로, 구형 브라우저나 일부 사내 프록시 환경에서는 진행바가 지연되거나 표시되지 않을 수 있음(결과 자체에는 영향 없음)
- 업로드 파일: 텍스트 추출이 가능한 PDF, 20MB 이하 (스캔 이미지 PDF 불가)

### MVP 단계 제한사항

- **스캔(이미지) PDF 미지원** — OCR 미적용
- **긴 약관은 전 구간을 다 보지 않음** — 특별약관·별표가 매우 많은 약관은 신호어 밀도 기준 상위 구간만 분석
- **법령 근거는 편집 요지 기반** — 조문 원문 실시간 연동은 향후 과제
- **콜드 분석 간 결과 편차** — LLM 특성상 매 분석이 완전히 동일하지 않음. 동일 문서는 캐시로 일관성 확보
- **분석 결과는 참고용이며 법적 자문이 아님**
